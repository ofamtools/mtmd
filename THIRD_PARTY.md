Copyright (c) 2025 Gaurav Gosain; see [LICENSE](LICENSE)). This file lists the
licence and notice files that stay in the tree, and why. The script
`scripts/ofam-prune.go` never deletes them; `third_party/` is generated by it.

## `third_party/`: modules the daemon links

tuios keeps several Go modules in its repository (`sketch`, `loom`, `plot`,
`progstatus`, `shot`, `swatch`, `tml`). mtmd does not keep their source: its
`go.mod` pins them at the same published versions as upstream, and the build
fetches them. The licence and notice files of each one the daemon links are
copied from the pinned version into `third_party/tuios.dev/MODULE/` by
`scripts/ofam-prune.go`, so they stay with this tree.

| File | Licence | Note |
|---|---|---|
| `third_party/tuios.dev/*/LICENSE` | MIT, Copyright (c) 2025 Gaurav Gosain | One per module. |
| `third_party/tuios.dev/sketch/raster/fonts/NOTICE` | SIL Open Font License 1.1 | The Arimo fonts that `sketch/raster` embeds. |

## Not in the tree

The other Go modules in `go.mod` (bubbletea, lipgloss, ultraviolet, chroma,
`charm.land/tone` (Apache-2.0), cobra, x/sys, ...) are imported, not copied.
Their licences are in their own modules. A binary that links them must carry
those notices: that is the host's job (lane `mtmd-3-notices`, `mtm licenses`).

## How each licence's conditions are met

- **MIT** (tuios, Charmbracelet, chroma): the copyright and permission notice
  must be in all copies or substantial portions. The text is in `LICENSE` and
  the files above, byte for byte as upstream has them, and `README.md` and
  `FORK.md` name the author.
- **BSD-3-Clause** (Go): source redistributions retain the notice, conditions
  and disclaimer: `LICENSE.golang`. A binary needs the same text in its
  documentation (host).
- **Apache-2.0** (herdr manifests, section 4): (a) the licence text is shipped
  as `LICENSE-herdr`; (b) files that are modified carry a prominent notice:
  each manifest's header says it is derived from herdr's, and mtmd does not
  change those files from upstream tuios (the prune only deletes files);
  (c) copyright, patent and attribution notices in the source are kept, since
  the headers are untouched; (d) herdr's repository has no `NOTICE` file, so
  there is none to reproduce. If herdr adds one, copy it here.
- **OFL 1.1** (Arimo): the licence and copyright are kept in the font NOTICE;
  the fonts are not sold on their own.
